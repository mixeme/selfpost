Backup

Take the whole instance with you, or bring one domain in from another SelfPost. Both files are secrets.

01

Full backup

data/ (database, DKIM keys, credentials, the queue), docker-compose.yml, .env and certs/ in one archive. Restore into an empty project directory and start the same SelfPost version. The reverse-proxy vhost is not included.

Keep this password: SelfPost does not store it, and the file cannot be opened without it.

02

Import a domain

A domain export from another instance — plain .json or encrypted .spde. Its DKIM key and application passwords come across, so the published DNS needs no change. The export itself is made on the domain's settings.

Asked only for an encrypted .spde file.
