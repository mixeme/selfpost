Outbound domains / example.org /

Delete example.org

This cannot be undone

Deleting example.org will:

  • permanently delete its DKIM signing key;
  • delete both applications (prod-server, alerts) with their credentials and sender bindings;
  • reload OpenDKIM so the domain is no longer signed.

The published DKIM record becomes invalid — remove it from DNS unless you plan to re-add the domain. Inbound domains are not touched.

Keep it

Moving it instead?

Export the domain first. The file carries the key and the application passwords, so the new instance needs no DNS change.
