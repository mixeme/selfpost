Domain settings

The things set once and rarely touched: where DMARC reports go, the sending ceiling, moving the domain elsewhere.

01

DMARC report address

A default belongs to a user and is set under their Account; a domain follows one named user, so two people sharing a domain never pull it two ways. Changing this changes the DMARC record to publish.

03

Export domain

One file with the DKIM key and every application's password hash — import it on another SelfPost and the published DNS needs no change. The file is a secret.

Keep this password: SelfPost does not store it, and the file cannot be opened without it.

02

Rate limit

active

Computed limit: 288 messages / 3600 s. Peak was 96 msg/h. Last recalculated yesterday 03:00 UTC.

Applies to every sender on this domain and cannot exceed level 1 (600 messages / 3600 s per client IP, set in .env). An application may carry its own limit above or below this one.

04

Delete domain

Removes the DKIM key and both applications. Asks once more before doing it.
